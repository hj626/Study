- 리액트와 뷰의 차이는
  HTML 안에 스크립트가 있는지(뷰), 스크립트안에 HTML이 있는지.

  템플릿은 필수

  데브옵스란: 개발과 운영 모두 하는것.
운영이란 : 사용자에게 보여지기까지 모든것. 빌드 배포 등등
CI : 컴파일/ 클라우드or 메인피시에 날려/ test
CD : 자동배포  종류도 3개정도있음. 배포되는동안 사용못하는것, 스바스로 배포중에도 사용할수 있는것, 일부 사용자만 배포된 버젼을 사용할수 있게 하는것.

깃에 푸쉬 하면 이벤트가 감지되어 자동으로 CI, CD가 진행됨.

리눅스 코만도 사용용도 
- 클라우드에는 GUI가 없음. 클라우드 관리 위해 리눅스서버에 접속함.
(ex.  에러기록파일이 있는 폴더로 이동하여 확인 하고 로그 파일을 열어봄.
이때 빌드가 잘되었는지, 현재 폴더 위치 확인 등)

- 빠른진행을 위해서 터미널을 활용하는데 이때 많이 사용됨.

이때 많이 사용하는 리눅스 명령어
pwd: 지금 내가 머물고 있는 폴더 위치를 화면에 표시.
ls: 지금 폴더안에 있는 파일과 목록모두 보여줌.(ls -al 하면 숨김처리 한것까지 보여줌)
cd 원하는 폴더로 이동 (ex. cd.. 이전으로 이동, cd dd dd파일로 이동)
mkdir: 새로운 폴더 만들기 (mkdir 폴더명)
rm: 삭제 (rm -rf 폴더명 / rm 파일명)
cat: 파일의 내용물 출력 (cat 파일명)
tail: 실시간 에러로그 감시하는데 가장 최신것을 보여줌.(하단)  tail -f 파일명
